# Security Policy

## Supported version

Security fixes are applied to the latest version available from the Chrome Web Store. Older releases and development ZIP files are not supported.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** option under the repository's Security tab to submit a private report. Do not open a public issue containing exploit details or sensitive information.

Include the affected version, reproduction steps, potential impact, and a suggested fix if you have one. You can expect an acknowledgement within seven days. After validation, the maintainer will coordinate a fix and disclosure timeline with the reporter.

General bugs that do not create a security or privacy risk should use the public bug-report template.
